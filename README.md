# 💡 Идея на миллион?

**Идея на миллион?** — веб-сервис для первичной проверки идеи цифрового продукта на подписочную модель.

Сервис помогает понять, стоит ли развивать идею как платный продукт за ежемесячную оплату, какие риски есть на старте и что проверить в первую очередь.

## Возможности

- оценка идеи по шкале от 0 до 100;
- расчёт подписочного потенциала;
- оценка силы боли клиента;
- оценка готовности платить;
- расчёт потенциального MRR;
- анализ реалистичности первой версии;
- сравнение двух идей;
- план проверки спроса на 7 дней;
- генерация структурированного отчёта;
- копирование отчёта;
- скачивание отчёта в формате Markdown;
- сохранение истории проверок в браузере.

## Как пользоваться

1. Откройте страницу сервиса.
2. Заполните параметры идеи.
3. Нажмите **Проверить идею**.
4. Изучите оценку, риски и план проверки.
5. При необходимости сравните идею со второй гипотезой.
6. Скопируйте или скачайте отчёт.

## Бизнес-логика

Итоговая оценка рассчитывается на основе нескольких факторов:

- сила боли клиента;
- срочность решения;
- частота возникновения проблемы;
- готовность платить;
- понятность аудитории;
- доступ к аудитории;
- конкуренция;
- отстройка;
- сложность запуска;
- причина возвращаться каждый месяц.

## Важное ограничение

Это инструмент первичной диагностики. Он не заменяет интервью с клиентами, анализ конкурентов, тест цены и реальные продажи.
